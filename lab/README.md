# lab/: ideas that did not pass the gate

A change goes into the engine only if `backtest.gate_v2` passes (see `CONTRIBUTING.md`).
Everything else gets a short write-up here: what was tried, the numbers, why it failed,
and what a later phase could try. Failed ideas are kept because "it did not work" is a
result, and so nobody tries the same thing again without knowing.
